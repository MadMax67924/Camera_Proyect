🎯 CÓMO USAR
─────────────────────────────────────────────────────────────────────────

  OPCIÓN 1: Script Rápido (Recomendado)
  ──────────────────────────────────────
    python3 quick_test.py
  
  → Menú interactivo con 5 opciones
  → Entrenar + evaluar automáticamente
  

  OPCIÓN 2: Manual
  ─────────────────
    # 1. Entrenar modelo mejorado
    python3 scripts/train_model_improved.py

    # 2. Evaluar con webcam
    python3 scripts/evaluate_model.py webcam

    # 3. Evaluar una imagen
    python3 scripts/evaluate_model.py image dataset/raw/FotosPablo/foto1.jpg

    # 4. Evaluar directorio completo
    python3 scripts/evaluate_model.py directory dataset/raw/FotosPablo


  OPCIÓN 3: Servidor Web
  ───────────────────────
    python3 app.py
  
  → Abre http://192.168.x.x:5000
  → Toggle reconocimiento desde navegador


🔧 AJUSTAR UMBRAL (Si es necesario)
─────────────────────────────────────────────────────────────────────────
  
  Problema                        | Solución
  ─────────────────────────────────────────────────────────────
  Muchos falsos positivos         | Aumentar umbral (75 → 90)
  Muchos falsos negativos         | Disminuir umbral (75 → 60)
  Baja precisión general          | Más fotos variadas + re-entrenar

💡 CONSEJOS PARA MEJOR PRECISIÓN
─────────────────────────────────────────────────────────────────────────
  1. Mínimo 30-50 fotos por persona
  2. Fotos variadas (ángulos, iluminación, expresiones)
  3. Buena calidad (evitar borrosas)
  4. Usar aumento de datos al entrenar
  5. Validar con evaluate_model.py antes de producción
