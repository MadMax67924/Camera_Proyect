                              5 COMANDOS RÁPIDOS
═════════════════════════════════════════════════════════════════════════════════

En tu Raspberry Pi:

  # 1. Preparar
  mkdir -p ~/camaraproject && cd ~/camaraproject

  # 2. Crear ambiente
  python3 -m venv venv && source venv/bin/activate

  # 3. Instalar (15 minutos)
  pip install --upgrade pip && pip install -r requirements_no_dlib.txt

  # 4. Capturar fotos
  python3 scripts/capture_faces.py "tu_nombre"

  # 5. Entrenar y ejecutar
  python3 scripts/train_model.py && python3 app.py

Accede desde tu navegador: http://192.168.1.xxx:5000

                            ERRORES COMUNES
═════════════════════════════════════════════════════════════════════════════════

"pip install tarda mucho"
  → Normal (10-15 min), opencv-python y scikit-learn compilan
  → No interrumpas, déjalo trabajar

"No module named cv2"
  → pip install opencv-python

"No module named flask"
  → pip install flask

"No se ve la cámara"
  → ls -la /dev/video*
  → Conecta USB, verifica con ls -la /dev/video*

"Modelo no encontrado"
  → Captura fotos primero: python3 scripts/capture_faces.py "nombre"
  → Luego entrena: python3 scripts/train_model.py

"Muy lento (1-2 FPS)"
  → Normal en Raspberry Pi 3
  → Sin dlib es más rápido de todas formas
